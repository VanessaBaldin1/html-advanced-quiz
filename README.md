
#  HTML Advanced Quiz

Um jogo interativo desenvolvido para testar conhecimentos avançados de HTML5, com foco em desenvolvedores web que desejam aprimorar suas habilidades.

## Sobre o projeto

O HTML Advanced Quiz apresenta 10 questões sobre recursos avançados do HTML, incluindo semântica, acessibilidade, formulários, performance e elementos modernos.

O projeto foi desenvolvido utilizando tecnologias nativas da web, sem frameworks ou bibliotecas de terceiros para a lógica do jogo.

##  Funcionalidades

- 10 questões de HTML avançado.
- Questões de escolha única e múltipla escolha.
- Questões de verdadeiro ou falso.
- Feedback educativo após cada resposta.
- Sistema automático de pontuação.
- Barra de progresso.
- Tela de resultado com percentual de acertos.
- Opção para reiniciar o desafio.
- Layout responsivo.
- Interface acessível e navegação por teclado.

##  Tecnologias

- HTML5
- CSS3
- JavaScript ES6+
- CSS Grid
- Flexbox
- CSS Variables
- DOM Manipulation

## 💻 Como executar

1. Clone o repositório:

   git clone https://github.com/SEU-USUARIO/html-advanced-quiz.git

2. Entre na pasta:

   cd html-advanced-quiz

3. Abra o arquivo index.html no navegador.

Você também pode utilizar a extensão Live Server no VS Code.

## Deploy

O projeto pode ser publicado gratuitamente utilizando GitHub Pages.
